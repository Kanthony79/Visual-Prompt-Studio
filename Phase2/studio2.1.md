# Visual Studio 2.1: Exploring Medium Through Prompt Variation

## Prompt A - Watercolor Painting

Create a watercolor painting of a young child building a colorful block tower in a bright and welcoming Pre-K classroom. Use soft colors, simple shapes, visible texture, strong contrast, and emphasis on the child and block tower. Use watercolor paint, round brushes, and watercolor paper. Use wet-on-wet painting and transparent layering to create gentle colors gradient and watery edges. Include classroom shelves and learning materials in the background.

## Prompt B - Linocut Print

Create a linocut print of the same young child building a block tower in a bright and welcoming Pre-k classroom. Use bold carved lines, simple shapes, strong contrast, visible texture, and emphasis on the child block tower. Carve the design into a linoleum block with carving tools, apply black ink with a brayer, and press it into paper. Add a few bright colors to the blocks. Include classroom shelves and learning materials in the background.
